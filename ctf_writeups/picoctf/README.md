# PicoCTF Write-ups

Solutions and notes for PicoCTF challenges studied in an authorized,
educational context.

Each challenge lives in its own folder:

```text
picoctf/
├── README.md
└── beginner-challenge-1/
    └── writeup.md
```

> Reminder: write explanations in your own words, never include real
> credentials, and use the `<...>` placeholders defined in the root
> `ctf_writeups/README.md`.
