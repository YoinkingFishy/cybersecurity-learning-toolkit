# TryHackMe Write-ups

Solutions and notes for TryHackMe rooms studied in an authorized,
educational context.

Each room lives in its own folder:

```text
tryhackme/
├── README.md
└── beginner-room-1/
    └── writeup.md
```

> Reminder: do not post live room answers where prohibited, and never include
> real credentials. Use the `<...>` placeholders defined in the root
> `ctf_writeups/README.md`.
